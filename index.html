Configuración de nube · Supabase

Paso 1: Crear base de datos

  1. Ve a supabase.com → crea cuenta gratis
  2. Clic en New project (nombre: altura-cafe)
  3. Espera ~2 minutos hasta que esté listo
  4. Ve a SQL Editor → pega y ejecuta este código:
-- Usuarios CREATE TABLE IF NOT EXISTS ac_users ( id BIGSERIAL PRIMARY KEY, name TEXT NOT NULL, username TEXT UNIQUE NOT NULL, password TEXT NOT NULL, role TEXT NOT NULL DEFAULT 'cajero' ); -- Productos CREATE TABLE IF NOT EXISTS ac_products ( id BIGSERIAL PRIMARY KEY, name TEXT NOT NULL, category TEXT NOT NULL, price NUMERIC NOT NULL ); -- Ventas CREATE TABLE IF NOT EXISTS ac_sales ( id BIGSERIAL PRIMARY KEY, date DATE NOT NULL, time TEXT NOT NULL, items JSONB NOT NULL, total NUMERIC NOT NULL, payment TEXT NOT NULL, type TEXT NOT NULL, comment TEXT DEFAULT '', cashier TEXT NOT NULL, created_at TIMESTAMPTZ DEFAULT NOW() ); -- Desactivar seguridad por filas (uso interno) ALTER TABLE ac_users DISABLE ROW LEVEL SECURITY; ALTER TABLE ac_products DISABLE ROW LEVEL SECURITY; ALTER TABLE ac_sales DISABLE ROW LEVEL SECURITY; -- Datos iniciales INSERT INTO ac_users (name,username,password,role) VALUES ('Administrador','admin','admin123','admin'), ('Cajero','cajero','cajero123','cajero') ON CONFLICT (username) DO NOTHING; INSERT INTO ac_products (name,category,price) VALUES ('Capuchino','Cafés',18), ('Americano','Cafés',15), ('Sandwich de lomito','Sandwiches',35), ('Sandwich de jamón y queso','Sandwiches',28), ('Coca Cola 500ml','Bebidas',12);

Paso 2: Pegar tus credenciales

  1. En Supabase: Project Settings → API
  2. Copia Project URL y anon public key
